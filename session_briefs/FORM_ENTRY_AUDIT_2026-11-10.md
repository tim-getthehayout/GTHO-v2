## 1. Scope, method and limits

This is a static audit of data-entry surfaces throughout `src/features/`, with existing-test evidence and isolated local probes. It covers farm records, reference editors, onboarding, settings and administration. Assistant, feedback and billing infrastructure are excluded; the existing assistant review wrapper was read only to distinguish its transaction boundary from manual saves. Read-only screens, filters and navigation are not record-entry forms. Calendar blocks navigate to the event forms below rather than providing a separate record-save path.

The pinned base was used in a new worktree, separate from Build's clone and the pending docs worktree. After fetch, `origin/main` was still the exact base SHA above. The checkout contains **76 entity modules**, not the earlier estimate of 74; several are infrastructure, not farm forms.

There is no `docs/` or `docs/audits/` at this base. Existing reviews and briefs live in `session_briefs/`, so this audit follows that convention. Framework AGENTS, team TEAM and project AGENTS were read before work. The explicit worktree task overrides the project's normal no-worktree-isolation instruction for this audit only.

Method:
- Inventory feature mutation calls, entity imports and secondary launchers, not just the five assistant-enabled sheets.
- Trace form payloads into `create()`, `validate()`, store calls and shape mappers. Compare checked-in SQL where a database constraint matters.
- Distinguish real DOM Save tests from entity-only, helper-only, source-text and mirrored-logic tests. Green tests do not establish coverage of an untested form.
- Run the unchanged suite, hook tests and lint. Additional probes use a throwaway script under `/tmp`: networking disabled, Supabase configuration blank, disposable JSDOM localStorage, no sync adapter.

**Tier meanings:** BROKEN NOW means a concrete code path rejects a normal manual save or loses/corrupts supplied data. RISKY FOR VOICE means a manual path exists but needs a safer contract, review, validation or save boundary; it does not claim every manual use fails. READY means the existing reviewed form boundary is usable, not permission for raw database writes. Counts are findings, not forms. Findings can cover several forms.

**Limits:** No live database or RLS verification, production writes, device smoke test, E2E execution, browser-crash/concurrent-device fault injection, or proof that every optional-field combination works. SQL evidence is checked-in migration history, not a live-schema claim. An aligned static trace is not a guarantee of live sync. Unproven concerns are marked suspected. OI-0210 rollout batches and review location A/B remain undecided pending Tim's review; this audit approves neither. OI-0211's separate voice-fix branch is unaffected.

## 2. Ranked findings

### BROKEN NOW — 11 findings, highest severity first

1. **FA-01 — Event-detail feed Add/Edit/Delete bypass located inventory.** `src/features/events/feed-entry-inline-form.js:140–178` writes feed entries and only `batches.remaining`; `src/features/events/detail.js:970–976` restores only that scalar on delete. Located deliveries maintain `batch_location_balances` and recompute remaining (`src/features/feed/batch-balances.js:49–71,170–184`). A real helper/store probe, after a located delivery of two and edit to one, leaves remaining **9** but balance total **8**. Reconciliation can erase the correction; storage availability is wrong now. **Direction:** give every feed add/edit/delete/removal the same source-location balance semantics, including reversals; preserve historical source information and handle unlocated legacy batches explicitly. No live-data repair in this audit.
2. **FA-02 — Locations' feed-type editor corrupts metric weight on save.** `src/features/locations/index.js:1147` always prefills kg converted to pounds and labels pounds; `:1161–1166` converts back only for imperial operations. In metric mode an unchanged save becomes approximately 2.20462 times the original kg, also rounded. `src/entities/feed-type.js:35,69` persists it as `defaultWeightKg/default_weight_kg`. **Direction:** share the unit-aware canonical editor or make display/save use the same declared unit. Add a real metric edit round-trip test.
3. **FA-03 — Breeding cannot save any subtype; extra fields would disappear.** `src/features/health/breeding.js:122–127` passes `date/time`, `expectedCalvingDate` and optionally `sireName`. `src/entities/animal-breeding-record.js:22–38,41–50,54–69` consumes `bredAt`, `expectedCalving`, and no `sireName`; only `ai/bull` are allowed, but the form defaults to and offers `heat` (`:35,50–53`). Actual DOM probes reject heat, AI and bull with missing bredAt; heat also has an invalid method. **Direction:** map timestamps/expected date; route heat to its actual record type; decide unknown-sire capture rather than silently dropping or overloading text.
4. **FA-04 — BCS never saves.** `src/features/health/bcs.js:74–75` passes date/time; `src/entities/animal-bcs-score.js:15–37,40–50` requires `scoredAt/scored_at`. No translation exists. Actual DOM Save leaves zero rows and reports scoredAt required. **Direction:** explicit local date/time-to-timestamp mapping and real-form tests. Preserve the sheep/goat 1–5 versus other-species 1–9 scale; the entity currently only requires a non-null score.
5. **FA-05 — Heat never saves.** `src/features/health/heat.js:55–56` passes date/time; `src/entities/animal-heat-record.js:14–30,33–41` needs `observedAt/observed_at`. Actual DOM Save leaves zero rows and reports observedAt required. **Direction:** explicit timestamp adapter and a real-sheet regression test.
6. **FA-06 — Group weights cannot commit a positive row.** `src/features/animals/index.js:1311–1317` passes `{ operationId, animalId, weightKg, date }`; `src/entities/animal-weight-record.js:17–44` requires `recordedAt` and source in `manual/group_update/calving/import`. The exact-payload probe reports both missing fields. The first positive row throws before later rows or the group-window split. **Direction:** map date, set the appropriate existing source, align composite per-head semantics and prevalidate the list.
7. **FA-07 — Move feed out cannot save.** `src/features/events/move-feed-out.js:248–252` passes `checkDate`; `src/entities/event-feed-check.js:15–37` consumes/requires `date`. The first add throws before removal/destination writes. Exact-payload probe confirms date required. **Direction:** correct the adapter, then test removal, source balance restoration and explicit destination paddock selection; a date-only fix does not make the remaining compound path safe.
8. **FA-08 — Locations' Apply input shortcut cannot save.** `src/features/locations/index.js:1305–1314` passes date/productName but not appliedAt or the selected product reference. `src/entities/amendment.js:19–44,47–61` requires appliedAt and has neither date nor productName. Exact-payload probe rejects appliedAt. **Direction:** use the full amendment form with source reference, quantity, units and location rows rather than a divergent shortcut.
9. **FA-09 — Animals' treatment-type manager cannot add a type.** `src/features/animals/index.js:1164–1179` offers category labels and passes `category`; `src/entities/treatment-type.js:13–32` consumes/requires `categoryId`. Exact-payload probe rejects categoryId. Settings correctly passes categoryId (`src/features/health/reference-tables.js:222–225`). **Direction:** reuse the reference editor with real category selection; never put a label in a foreign-key slot.
10. **FA-10 — Animals' sire manager silently drops registration and EPD text.** `src/features/animals/index.js:1249–1250` passes regNumber/epds; `src/entities/ai-bull.js:15–25,38–48` supports regNum, not regNumber, and no epds field/column. Exact-payload probe validates but drops both. Quick Add bull/settings use supported keys. **Direction:** use regNum; take EPD storage to Tim/schema-first, not an invented column.
11. **FA-11 — Locations' soil-test shortcut loses organic matter and zeros.** `src/features/locations/index.js:627–634` passes organicMatterPct; `src/entities/soil-test.js:34–64,78–104` consumes/maps organicMatter/organic_matter. Exact-payload probe validates but drops the value. `parseFloat(...) || null` also turns entered zero values into null. **Direction:** share the full soil-test adapter and distinguish blank from zero. The full form uses organicMatter (`src/features/amendments/soil-tests.js:168–184`).

### RISKY FOR VOICE — 11 findings, highest impact first

12. **FA-12 — Manual compound saves are not recoverable transactions (extends OI-0213).** Feeding preflights rows, but writes sequentially (`src/features/feed/delivery.js:516–558`): deduction, remaining, entries, optional check/items. The pattern also affects event/membership/window saves, batches, calving, surveys, harvest, amendments and assignments (register below). No direct runDurableWrite call is present in these manual forms. `src/data/store.js:63–88` provides a journal; standalone calls persist independently (`:97–108`). Existing assistant-confirmed forms ARE wrapped at `src/features/assistant/entry-review.js:57–69`; do not describe that route as unjournalled. **Direction:** prevalidate/commit each complete logical operation with recovery/idempotency; keep prompts/async steps outside the synchronous journal. Local durability is not a server-wide SQL transaction or cross-device reservation.
13. **FA-13 — Most forms have no model-fill/readback contract.** Current bindings cover Move, Place, feeding, Treatment and Calving; e.g. `src/features/health/treatment.js:90`. Add batch (`src/features/feed/index.js:1383–1440`), Weight (`health/weight.js:98–123`), Feed check (`feed/check.js:277–294`) and transfer (`feed/index.js:1134–1219`) use DOM/closure state without equivalent bindings. **Direction:** catalog actual fields, conditions, unit basis and readback; reject unknown keys; expose explicit supported actions, not all entity FIELDS.
14. **FA-14 — Move/Place and event mutations require a live window graph.** `src/features/events/wizard-shared.js:339–435` fans out event/paddock/group windows; Move closes source windows and transfers feed (`move-wizard.js:604–785`). Cohorts, scoped-last moves, join-existing, strip percentages, dates and conditional observations change the write set. **Direction:** resolve operation/farm/group/event/window context, recalculate placement before confirmation and review scope/destinations. Preserve existing journal coverage in OI-0208 chat.
15. **FA-15 — Calving is compound and has a late decision.** `src/features/health/calving.js:130–201` can create calf/weight/membership, split windows, record birth, clear dam confirmedBred, then offer reclassification to the first matching cow class. Stillbirth-with-tag creates an animal with ordinary defaults; intended active status needs confirmation, not an invented fix. **Direction:** gather conditional choices before commit, review every side effect and settle stillbirth/class behavior with Tim. Preserve the existing durable review route.
16. **FA-16 — Animal/group edits replace memberships and may reduce composite lots.** `src/features/animals/index.js:595–624,854–872,2063–2128` closes/creates memberships, mirrors dam/birth edits, adds lot weights and invokes reduction prompts. `animals/composite.js:84–98` changes heads and proportional weight history. **Direction:** separate individual/composite schemas, review before/after sets and derived heads/weights; make the complete operation recoverable. Declare per-head display versus stored total.
17. **FA-17 — History editors can write before Save and delete history.** `src/features/events/edit-group-window.js:146–150` and `edit-paddock-window.js:303–306` save on blur without connected/no-op guards in those handlers. `edit-feed-check.js:269–324` can resnap/delete later items and empty parents. Retro-place compensates caught failure (`retro-place.js:105–134`), not crashes. **Direction:** no blur writes during model filling; explicit review of destructive history changes and recoverable commit. Phantom-save risk is suspected, not reproduced on a device here.
18. **FA-18 — Form/validator/SQL constraints differ.** BCS only requires non-null score; numeric finite/range checks are inconsistent. Paddock areaPct is not range-checked in `src/entities/event-paddock-window.js:41–51`, but SQL requires >0 and <=100 (`supabase/migrations/005_d5_events.sql:54`). Editor zero falls back to 100 and high values are not clamped (`edit-paddock-window.js:229–246`). Batch quantity has a type check (`src/entities/batch.js:47–56`); balances reject negatives. **Direction:** reconcile bounds/enums/conditional references/blank versus zero and preflight every row. Negative Add batch can pass its parent validator before a child balance fails: traced failure order, not a production-incident claim.
19. **FA-19 — Surveys/observations combine lists, autosave and replace-all.** `src/features/locations/index.js:756–772` removes drafts before recreating; `:1010–1027` can replace committed observations. Alternate surveys writes observations then status (`surveys/index.js:378–408`). Cards derive units/defaults and distinguish untouched quality. **Direction:** explicit location-to-reading lists and atomic replace/finish; partial model lists must not delete unmentioned locations or turn an untouched slider into an observation.
20. **FA-20 — Harvest/amendments need quantity, unit and allocation contracts.** Harvest writes event+batch+field per accepted row (`src/features/harvest/index.js:396–423`), skips incomplete rows and does not place batches in storage balances. Amendment writes parent+N children (`amendments/entry.js:343–396`), divides quantity evenly and multiplies raw quantity by percentages to store nutrient kg, without a unit conversion in this save. **Direction:** review rows/storage/source/units/allocation before exposure. Non-kg/manure nutrient correctness is suspected pending domain verification; do not invent conversion/distribution rules.
21. **FA-21 — Defaults can turn incomplete speech into invented facts.** Weight/Calving use noon UTC (`src/features/health/weight.js:108`, `calving.js:130`); Treatment uses local time/default noon (`treatment.js:82`); observations use capture time even for historical closes (`events/close.js:243`). Batch defaults purchase/first type (`feed/index.js:1258–1262,1283–1289`); transfer prefills all holding stock (`:1156–1167`). **Direction:** declare date-only/instant/timezone and display/stored units; visibly offer and read back defaults. Resolve scoped names, not first matches.
22. **FA-22 — Config/admin/global records stay outside farm voice rollout.** Dose/product units have no operationId (`src/entities/dose-unit.js:3–18`, `input-product-unit.js:3–18`); the journal scope check rejects global records (`src/data/store.js:92–95`). Member writes bypass store/journal (`src/features/settings/member-management.js:319–331,484–494,520–575`). Onboarding seeds many rows (`onboarding/index.js:294–401`). **Direction:** exclude from OI-0210; verify admin permissions/live sync separately. Mocked member tests do not certify live RLS/offline behavior. Tracking RLS authorizes no policy change.

## 5. Cross-cutting patterns

- **Entity schema is not form schema.** `create()` enumerates keys and often drops unknown ones; `update()` can retain an extra JS key the mapper omits. Canonical round-trip tests can pass while a form sends wrong keys. All OI-0214 starting hypotheses are confirmed: BCS date/time vs scoredAt; heat vs observedAt; breeding vs bredAt, expectedCalvingDate vs expectedCalving and heat vs ai/bull. sireName is another breeding drop.
- **Duplicate forms drift.** Locations has parallel soil/feed-type/amendment editors; Animals has parallel treatment/sire managers. Prefer one manual form contract over divergent save objects.
- **Journal matrix:** reviewed assistant Move/Place/feeding/Treatment/Calving use runDurableWrite. Their manual counterparts do not. Animal/group/cull/split/weight, batch add/edit/transfer/adjust/delete, checks/history edits, event open/close/reopen/retro, surveys/harvest/amendments/todo assignment operations are independent mutations. Retro-place's compensation is not process-loss recovery. Onboarding is compound without one boundary. Member management bypasses the machinery. None of this claims a multi-table server transaction.
- **Preflight is not atomicity.** Delivery validates planned rows and shared pools, but later standalone persistence failure can leave earlier writes. Test storage throws, replay and sync acknowledgements separately.
- **Totals are not holdings.** Legacy inline corrections/deletions/return-to-batch paths use scalar remaining, unlike location-aware delivery. Every reversal must maintain the same invariant. Adjustment edits apply a difference against a historical adjustment, not a replacement of today's inventory.
- **Time and units differ by form.** Noon UTC, local wall time, today, capture time and historical date are distinct. Convert speech to the display units the real form expects before its metric conversion, not twice. Defaults need visible readback.
- **Enums/required are layered.** Form can be stricter than entity (Treatment type); entity can require fields the form omits (broken health); SQL can constrain what JS does not (areaPct). IDs, conditional references, ordered dates, finite/ranged numerics and lists need deterministic validation.
- **Scoped names/global references:** resolve operation/farm-scoped animal/group/event/location/batch/type identities; distinguish source and destination; never silently pick the first match. Global units have no operation field and cannot enter the scoped journal unchanged.
- **Tests must cross the whole boundary.** The suite is green despite broken forms. Entity tests construct correct keys; mirrored tests do not execute forms. Add actual field population -> Save -> entity/store -> mapped queued payload tests, assert counts/balances/memberships/rollback, then separately approved device/E2E/live sync checks.
